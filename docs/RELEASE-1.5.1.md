# AlienGamer Mode 1.5.1

Revisión correctiva de la primera versión multidisplay.

## Correcciones

- Las instalaciones procedentes de 1.4 ya no mezclan preferencias de módulos antiguas con el diseño multidisplay nuevo.
- La primera migración crea una distribución limpia con todos los módulos visibles y con el menú de bandeja sincronizado.
- Idioma, hardware elegido, pantalla, almacenamiento y fondo compatible se conservan.
- El editor **Pantallas y distribución...** ya no bloquea el icono de bandeja mientras está abierto.
- Si el editor falla, se conserva un registro y se muestra el motivo.
- Desde 1.5.1, configuraciones posteriores con esquema 3 sí conservan íntegramente las posiciones y preferencias multidisplay.

## Prueba recomendada

1. Instalar sobre 1.4 o 1.5.0.
2. Confirmar que skin y bandeja muestran el mismo estado de módulos.
3. Abrir **Pantallas y distribución...** y comprobar que la bandeja sigue respondiendo.
4. Guardar una distribución, detener el monitor y volver a activarlo.
