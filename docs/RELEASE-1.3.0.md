# AlienGamer Mode 1.3.0

## Event Intelligence

- Búfer circular de 60 segundos previos a cada grabación.
- Varias marcas de incidente por sesión con análisis temporal de ±15 segundos.
- Puntuación de estabilidad 0–100 explicada mediante P95, P99, picos y variación de *frame time*.
- Interpretación, evidencia y recomendación preliminares sin presentar correlaciones como causas demostradas.
- Datos brutos completos en Excel y CSV.
- Comparación con la sesión anterior y asistente de privacidad.
- Modo compacto FPS centrado y responsivo.

La versión conserva selección de idioma español/inglés, cierre coordinado mediante **OFF**, validación de sensores, módulos persistentes y protección OLED.

## Requisitos

- Windows 10/11 de 64 bits.
- Rainmeter 4.5 o posterior.
- HWiNFO64 8.20 o posterior con memoria compartida.
- Microsoft Excel para generar el reporte `.xlsx`.

## Alcance del análisis

El reporte ayuda a organizar evidencia y detectar correlaciones. No sustituye telemetría del juego, pruebas SMART completas, trazas ETW, análisis de red ni revisión profesional.
