# AlienGamer Mode 1.5.2

Revisión correctiva del editor visual multidisplay.

## Correcciones

- **Pantallas y distribución...** vuelve a abrir una ventana visible sin dejar una consola de PowerShell en pantalla.
- Si Windows no llega a crear la ventana, la opción del menú se reactiva automáticamente después de unos segundos para permitir un nuevo intento.
- Usar **OFF** y activar nuevamente el monitor ya no deja el editor bloqueado por un proceso invisible.
- El instalador solicita el cierre ordenado del agente anterior antes de reemplazar archivos.

## Configuración inicial

Después de cualquier instalación, AlienGamer Mode inicia el monitor y abre el editor visual al terminar. En una actualización carga la distribución existente sin restablecerla. Allí se puede:

- elegir una o varias pantallas;
- activar u ocultar cada módulo;
- arrastrar bloques;
- aplicar diseños predefinidos;
- configurar el fondo por pantalla.

Las distribuciones ya guardadas por 1.5.0 o 1.5.1 se respetan y no se restablecen.
