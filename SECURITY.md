# Política de seguridad

## Versiones compatibles

La versión más reciente publicada es la única que recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No publiques credenciales, registros privados ni detalles explotables en una incidencia pública. Usa el reporte privado de vulnerabilidades de GitHub cuando esté disponible en la sección **Security** del repositorio.

Incluye una descripción, pasos mínimos para reproducir el problema, impacto estimado y versión afectada. No adjuntes archivos generados por el monitor sin comprobar primero que no contienen información sensible.
